# DevJourney – Developer Learning Journey Tracker

A frontend-focused React application for tracking programming skills, learning activities, goals, streaks, achievements and analytics.

## Stack
React, JavaScript, Vite, React Router, Recharts, Lucide React and Local Storage.

## Run
```bash
npm install
npm run dev
```

## Features
- Multi-step onboarding
- Dashboard with learning statistics
- Interactive career roadmap
- Daily learning tracker and activity timeline
- Goals with progress and deadlines
- Streaks, achievements and journey score
- Analytics charts and smart insights
- Dark/light mode
- Export data as JSON
- Local Storage persistence
